Found by Accident

A Race Condition Lived in Production
for 1 Month. Hidden from Sequential Tests.

Standard tests couldn't catch it — they were single-thread. Only when we split the monoliths and ran 4 parallel browser projects did the collision surface.

Root Cause
datetime.now()
Same microsecond → same JWT →
unique_violation in PostgreSQL
The Fix
jti: uuid.uuid4()
One line in the token payload.
Every token is now unique.

What I Learned

Three Honest Takeaways

1️⃣

AI amplifies your prompt quality

"Write tests" generated 4,000 lines of tech debt. A specific prompt with modular structure would have saved Phase 2 entirely.

2️⃣

Refactoring finds bugs that testing misses

A race condition lived for 1 month in the API. Sequential tests couldn't catch it — only parallel execution across 4 browser projects exposed the collision.

3️⃣

Free AI is a treadmill, not a foundation

15 tools in 2 months. 6 are gone. 9 remain. Diversify, rotate, never depend on a single provider.
